# Narrative Interact

ローカルLLMで動くインタラクティブフィクションシステム。  
ジャンルとタイトルを入力するだけで、LLMがGM（ゲームマスター）として物語を自動生成する。プレイヤーは主人公として自由に行動を入力し、その結果に応じてGMが物語を進める。

## 特徴

- **完全ローカル動作**：LM Studio経由でローカルLLMを使用。外部APIは不要
- **ジャンル・タイトル自由**：日常、ミステリー、ファンタジー、ホラーなど何でも指定可能
- **プロット自動生成**：ゲーム開始時にLLMが物語の骨格（登場人物・葛藤・反転・エンディング）を設計する
- **ダイス判定**：行動の成否をダイスで決定。成功・失敗がGMの描写に反映される
- **セーブ・ロード**：途中でセーブして後から再開できる
- **物語の軸を選択**：プロット拘束度を4段階から選べる

## 遊び方

### 1. 起動とゲーム設定

```bash
python main.py
```

起動後、以下を順番に入力する。

```
ジャンル: ミステリー
タイトル: 消えた遺言状
```

続いて物語の軸を選択する。

| 選択 | モード | 内容 |
|------|--------|------|
| 1 | プロット参照・自由 | プロットは参考情報。逸脱しても構わない |
| 2 | プロット参照・緩拘束（おすすめ） | プロットに沿いつつ自由行動を尊重 |
| 3 | プロット参照・強拘束 | 反転・選択・失敗をプロット通りに発生させる |
| 4 | プロットなし・即興 | プロットを生成せずGMが即興で物語を作る |

### 2. 行動入力

GMの描写を読んで、主人公として行動を入力する。

```
> 机の引き出しを開ける
> 老人に話しかける
> 窓から外を見る
```

行動は自由。GMはプレイヤーの行動を否定せず、結果として世界を変化させる。

### 3. ダイス判定

行動によってはダイス判定が発生し、成否がGMの描写に反映される。難易度は起動時に選択できる（易しい・標準・厳しい）。

### 4. エンディング

物語の主要な葛藤が解消されるとGMがエンディングを描写して物語が終わる。

## ゲーム中のコマンド

| コマンド | 機能 |
|---------|------|
| `/hint` | 行動候補を3〜4つ表示 |
| `/save` | セーブ |
| `/load` | ロード |
| `/retry` または `/r` | 直前のGM応答を再生成 |
| `/quit` | セーブせずに終了 |
| `/help` または `/h` | コマンド一覧 |

## 動作環境

- Python 3.10以上
- [LM Studio](https://lmstudio.ai/) （ローカルサーバーとして起動）
- 推奨モデル：Gemma4 12B
- 推奨コンテキスト長：32,768トークン以上（システムプロンプトが約7,700トークン、物語1本あたり20〜40ターンを想定）

## セットアップ

```bash
git clone https://github.com/naoki-Kamishiro/narrative-interact.git
cd narrative-interact
pip install -r requirements.txt
```

`config.py` でLM StudioのエンドポイントとモデルIDを設定する。

```python
# config.py
LM_STUDIO_URL = "http://localhost:1234/v1"  # LM StudioのデフォルトURL
MAX_TOKENS    = 16384                        # 1ターンあたりの最大出力トークン数
TEMPERATURE   = 0.85
```

モデルIDの指定は不要（LM Studioはロード中のモデルを自動で使用する）。  
コンテキスト長（32,768トークン以上を推奨）はLM Studio側のモデル設定で変更すること。

## 自動プレイ（デバッグ用）

プレイヤー入力もLLMが担当するモード。プロンプト検証・挙動確認に使用する。

```bash
python main.py --auto normal    # 通常モード
python main.py --auto deviate   # 逸脱モード（GM制約を意図的に超える行動）
python main.py --auto normal --debug  # デバッグ出力あり
```

## 既知の不具合

- **自動プレイ時のループ**：プレイヤーLLMが「握る→握りしめる→力を込める」のように動詞を微妙に変えながら同じ対象への行動を繰り返すことがある。自動プレイはデバッグ用途のため現状未対処。
- **プレイヤーLLMによる内面描写**：自動プレイ時にプレイヤーLLMが「覚悟を決める」「感謝の気持ちを伝える」のような内面行動を出力することがある。GM側で対処しているが完全ではない。
